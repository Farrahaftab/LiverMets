# LiverMets CRLM survival analysis: results package

## Contents
- `LiverMets_PhD_Survival_Analysis.ipynb` - executed notebook (all outputs produced by a top-to-bottom run, seed 42, 0 error outputs). Upload to Colab and run to reproduce.
- `livermets_survival_colab.py` - source the notebook is generated from (cell-marked).
- `build_notebook.py`, `run_notebook.py`, `requirements.txt`.
- `results/tables/` - T00-T23 CSV tables (row audit, column inventory, date checks, cohort flow, survival, Cox, PH tests, RMST, model performance, calibration, benchmarks, PSM, sensitivity, Table 1).

- `reproducibility_report.md` - generated by the notebook from the run.

No patient-level data are included. Working files (Parquet extract) stay in the run's WORK_DIR.

## Key results (from the executed run)
- Combined patients: 29,565 (Part 1: 14,782; Part 2: 14,783). The header row is not a patient.
- TNM-complete: 19,465 (10,100 excluded), matching the earlier published flow.
- OS analysis cohort: 13,285; 4,921 deaths; time zero = liver metastasis diagnosis.
- Phenotypes: the pre-specified thresholds (median OS >= 6 years for Favourable) gave **no Favourable node**. Only Intermediate (n=3,580; median OS 6.09 y) and Adverse (n=9,705; median OS 4.08 y) were populated. Thresholds were not changed.
- Model performance (C-index): internal 0.63 (Cox 0.63, RSF 0.63, GBS 0.63); temporal 0.65-0.66. Time-dependent AUC at 5 years 0.65-0.71. Phenotype rank alone 0.55.
- Benchmarks (apparent, complete cases): Fong CRS C = 0.57 (n=6,082); Nordlinger-type unweighted C = 0.57 (n=10,499). Basingstoke Predictive Index not computed (differentiation grade not in export).
- Treatment (Surgery+Chemo vs Surgery_Only), propensity-matched within phenotype: Intermediate HR 0.81 (0.67-0.98); Adverse HR 0.70 (0.62-0.78). Matched balance: max |SMD| 0.07.

## Caveats
- Only two phenotype groups exist under the pre-specified thresholds, so the three-phenotype design could not be completed.
- Proportional-hazards tests fail for the treatment term (p < 0.001) and for the Adverse indicator; HRs are average effects over follow-up.
- Treatment is decided after time zero; the 6-month landmark analysis did not remove residual bias in the Adverse group (HR 0.81).
- The earlier derived dataset (SURVIVAL_YEARS, VITAL_STATUS, TREATMENT) was not available; survival definitions were rebuilt from raw dates, so the earlier survival-eligible count (14,759) is not reproduced (this run: 13,285).
- Sensitivity analyses (T22) show the treatment HR is stable across time zero, era, and RFS, but the validation-era HR (0.67) differs from the training era (0.79).
