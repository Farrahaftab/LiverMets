# LiverMets : Interpretable Machine Learning for Clinical Outcome Analysis

Research code supporting my PhD work in **AI for Healthcare**, focusing on interpretable machine learning and survival analysis for patients with colorectal liver metastases (CRLM).

## 🔬 Research Overview

This project investigates whether clinically interpretable machine learning approaches can support risk stratification and outcome analysis in colorectal liver metastases.

The work combines traditional survival analysis with machine learning and explainability techniques to investigate clinically meaningful patient subgroups and prognostic factors.

## 🧠 Methods

The analytical workflow includes:

- Survival analysis
- Kaplan–Meier estimation
- Log-rank testing
- Cox proportional hazards modelling
- Decision-tree-based patient stratification
- Model discrimination and validation
- Temporal validation
- Explainable AI (XAI)
- SHAP-based model interpretation
- Subgroup and treatment-effect analysis

## 🛠️ Technologies

- Python
- pandas
- NumPy
- scikit-learn
- matplotlib
- SHAP
- Survival-analysis libraries
